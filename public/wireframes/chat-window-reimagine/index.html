Meridian Chat — UI Reimagine

4 clickable wireframe concepts · 2026-06-13

Inspire Genius · Internal review

The problem

The current chat surface stacks five horizontal bands above the conversation (workspace header → "Meridian + Aura" pill row → tab strip → response metadata strip → composer), leaving only ~60% of the viewport for the actual conversation. Sources, "Rate this response," and Observability are inline disclosure links that get visually lost. The composer is small relative to the empty space around it. These four concepts each take a different stance on how to fix that.

Concept A Focused Canvas

Strip the chrome. Just the conversation.

Sidebar collapses to a thin icon rail. The Meridian pill row, tab strip, and metadata strip merge into one command bar. Sources / rate / observability live in a single Trace drawer.
Concept B Workbench

Three columns. Context lives next to the chat.

Persistent right-side context panel with tabs for Active Doc, Sources, Session Info, and Agents Consulted. Nothing modal-switches. Power-user workbench feel.
Concept C Threaded

Linear-style. One column, rich per-message metadata.

Each Meridian response carries a slim strip: routed agents, sources count, latency, confidence. Click to expand inline. No tabs, no second header.
Concept D Agent Dashboard

Chat is one card among many.

Active agents strip at top, large chat card, plus suggested next questions and recent documents. Best when the chat is one of several active activities.

How to use these: click any concept above to open the clickable wireframe. Sidebar items, tabs, message metadata, drawers, and composer states are all clickable in each concept. None of these connect to real services — they're static surfaces for review only.
